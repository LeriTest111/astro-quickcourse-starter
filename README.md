# Astro Quick Course Starter

Lean prototype proving that a separate Astro course repository can consume Quick Course Kit release `0.1.0`.

## Kit dependency

The Starter uses the generated local Kit release through `@quick-course-kit/local-release`. Do not copy or edit Kit components inside this repository.

## Run

```text
npm install
npm run dev
npm run build
```

## Future

Course Builder instructions, storyboard mapping, course content structure and SCORM packaging will be added after this consumption proof.
